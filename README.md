# London_Cheese_Academy
チーズアカデミーロンドン

## 課題内容（どんな作品か）
課題がチーズアカデミー東京でしたが、今、住んでいるロンドンに変更しました。
自社のホームページもあることから、他に作りたいLPがなかったので基本に準じて、課題を一旦ほぼ同じものを作ることにしてみました。


## 工夫した点・こだわった点
工夫した点はロンドンなので、地下鉄で言われるMind the gapなどのロンドン風なものを入れるようにしてみました。
作りたいLPは無かったので、追加の機能ということで、次回の予習を兼ねて下記の機能追加をしました。

      3-1  ルーレット機能
      Contactから送信を押すと、チーズ風のルーレットが回り、当たりかはずれが表示されます。(八分の１で当たります。)
      当たりの場合はクーポンが表示され、20%オフでチーズアカデミーロンドンに入学できるようになるという形で考えました。
           ※動画ははずれです。
       3-2 日英の言語の切り替え
      また仕事柄、日本語と英語の切り替えが必要になることが多いので、英語と日本語の切り替え機能を追加してみました。
      日英切り替えとルーレットはJavaScriptを用いており、この箇所はまだ未学習なためAIにかなりの部分を頼りました。ただJavaScriptを用いるとHPに様々な機能を追加出来ることが分か
       り、大変学びになりました。

## 難しかった点・次回トライしたいこと（又は機能）
次回は動きのあるWebsiteに挑戦したいと思います。

## フリー項目（感想、シェアしたいこと等なんでも）
一度、AIを活用して作成してみましたが、再度、勉強の為一から手で作り直しました。
初回から分からないところは都度、AIに聞くようにしていましたが、直接コードを直してもらうと勉強にならないので、直接コードを変更してもらうわず、
提案してもらい、良い案を自分で書いていくようにしました。初回に作ったときに思ったことは、都度、AIに聞くとClass名の統一性やコードの書き方がバラバラになる気がしました。
なので、コードを書く前に仕様やネーミングルールをしっかり最初に固めておいて、それをベースに分からないところをAIに聞くということが良いと感じました。
